# 🎬 Video Streaming Platform

A feature-rich web-based video streaming platform project featuring user authentication, video uploading and streaming, subscriptions, user management, and an admin dashboard.

## 🚀 Features

### 🔐 User Authentication
- Secure user registration and login.
- Password recovery.
- Role-based access control.

### 📤 Video Upload & Streaming
- High-performance video uploading.
- Video processing.
- Smooth media playback.

### 💳 Subscriptions
- Paid subscription tier management.
- Subscriber-exclusive content capabilities.

### 👥 User Management
- Profile customization.
- Channel management.
- Viewer engagement tools.

### 📊 Admin Dashboard
- Comprehensive platform overview.
- Analytics and content moderation.
- User oversight.

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript / Modern Framework

## ⚙️ Installation & Setup

Follow these steps to get the project up and running locally on your machine.

1. **Place the project folder** in the `htdocs` directory.
2. **Start the XAMPP server.**
3. **Import the database.**
4. **Visit the project** in your browser:

   http://localhost/stackcoders/
